# App 当前交互说明

本文记录 ListenBook 手机端已经生效的页面行为，作为 UI 开发和真机回归的现行基线。产品与内容架构以 [`CLAUDE.md`](../CLAUDE.md) 为准，服务端接口与部署以 [`server/README.md`](../server/README.md) 为准。

## 主框架

- 底部四个 Tab 为“首页 / 书架 / 记录 / 我的”。
- 单击 Tab 切换页面；在 300ms 内双击当前 Tab，页面滚动到顶部。
- 首页双击 Tab 不再刷新数据。首页刷新只通过下拉手势触发。
- 播放中显示底部迷你播放器，并与浮动 Tab 栏共同避让页面内容。

## 首页

### 顶部区域

- 搜索框固定在页面顶部，不随内容滚动。
- 未进入搜索结果态时，搜索框下方显示单行横向分类标签；“推荐”及所有分类都可横向滚动访问。
- 搜索结果态改为显示结果数量和视图切换，不显示分类标签。

### 首次加载

- 首次进入“推荐”且尚无板块数据时，在固定顶栏下方显示两组书籍板块骨架。
- 骨架使用明暗呼吸动画，不显示“加载推荐中”文字，也不叠加居中的加载圈。
- 分类首次加载和搜索加载仍可使用加载圈，但颜色必须来自 `AppColor.Brand`。

### 下拉刷新

- “推荐”和具体分类页面支持下拉刷新；搜索结果页面禁用下拉刷新。
- 刷新指示器放在分类标签与内容列表之间的下拉空白区，不使用系统默认顶栏指示器。
- 指示器使用项目橙色 `AppColor.Brand`。
- 刷新过程中保留现有内容，数据返回后整体替换，减少空白闪烁。
- 无论请求成功或失败，都必须在结束时清除 `isRefreshing` 和刷新状态，让指示器立即消失。

### 推荐板块

- 第一个板块与顶部分类区域保持 `AppSpace.Md`（16vp）间距。
- 每个板块标题右侧都显示“更多”入口，进入 `BlockMorePage` 查看对应分类的后续内容。
- 板块内容根据来源配置使用横向封面列表或纵向书籍列表。

## 收听记录

- 页面上半部分显示累计时长、连续天数等统计摘要，下方为“收听历史”。
- 标题右侧“编辑”进入批量管理；长按任意记录也可进入多选并选中该项。
- 编辑模式提供“全选 / 删除 / 取消”，删除前需确认。
- 单条记录右侧不显示三点菜单，避免与顶部编辑功能重复。
- 普通模式下点击记录主体进入书籍详情，点击右侧播放按钮从记录位置继续播放。

## 主题与加载

- 项目品牌色统一通过 `entry/src/main/ets/theme/Theme.ets` 中的 `AppColor.Brand` 获取。
- 浅色主题的 `app_brand` 当前为 `#FF6B3D`；深浅模式都应读取资源，不在页面内复制颜色值。
- 新增或修改 `LoadingProgress` 时必须显式设置 `.color(AppColor.Brand)`，避免出现 HarmonyOS 默认蓝色。
- HarmonyOS 7 需要材质层次的悬浮控件使用 `AppMaterial.InteractiveThin`，播放器弹层和配置 Sheet 使用 `AppMaterial.SurfaceRegular`。
- 首页搜索框和分类标签使用 `AppMaterial.InteractiveThin` 原生沉浸光感材质，不注入品牌材质色且不叠加底部阴影；仅选中标签的文字和下划线使用主题色。暂不启用滚动折叠和标签吸顶。

## 播放器与系统控制

- 锁屏和控制中心媒体卡片支持独立的后退 10 秒与前进 30 秒，命令会按当前进度裁剪到 `0..duration` 后真实 seek。
- 在线章节边播边使用 HarmonyOS 系统托管缓存；已完整下载或本地导入的章节仍从沙箱文件播放。
- 系统托管缓存不是“已下载章节”，不出现在下载管理页；需要长期离线保留时仍使用章节下载功能。

## 页面、接口与数据

| 页面 / 交互 | 主要代码 | 接口或服务 | 数据位置 |
|---|---|---|---|
| 首页推荐与分类 | `HomePage.ets`、`BlockMorePage.ets` | `BookSourceService`、`BuiltInDispatcher` | 内置源返回的板块与分类数据 |
| 首页搜索 | `HomePage.ets` | 听友 FM 直连 + `GET /api/v1/audio-books/search` | 页面数据源与短期搜索缓存 |
| Tab 双击回顶 | `MainPage.ets` | 各页面注册的 `Scroller` | 仅运行时状态 |
| 收听记录 | `ReadingStatsPage.ets` | `StatsService`、`PreferenceService`、`PlaybackStore` | 设备本地统计、历史和播放进度 |
| 继续播放 | `ReadingStatsPage.ets`、`AudioService` | 按书籍来源解析章节与音频 | 本地进度 + 来源章节数据 |

## UI 回归清单

1. 清除或首次启动首页数据后，确认推荐区显示骨架屏且没有“加载推荐中”。
2. 在推荐页下拉，确认橙色指示器位于分类栏与列表之间，松手后完成刷新并消失。
3. 切换到具体分类后重复下拉检查；进入搜索结果后确认不能触发下拉刷新。
4. 确认“最近更新”等第一个推荐板块与分类栏有 16vp 间距，并且每个板块都有“更多”入口。
5. 在四个 Tab 分别滚动后双击当前 Tab，确认只回到顶部，不触发首页重新加载。
6. 在记录页分别验证“编辑”和长按进入多选、全选、取消、确认删除及继续播放。
7. 检查首页、更多页、详情页等可见加载圈均为项目橙色，不出现系统默认蓝色。
8. 在 HarmonyOS 7 真机检查首页顶部与列表颜色一致，并确认搜索框、分类标签的沉浸光感和交互响应正常。
9. 打开播放器的章节、定时、跳过和倍速弹层，确认材质、圆角、阴影和关闭手势正常且无内容重叠。
10. 从锁屏或控制中心分别触发后退和前进，确认进度变化为 10 秒和 30 秒，并在章节首尾正确裁剪。
11. 连续播放同一在线章节两次，确认播放正常；再下载章节，确认下载管理与本地播放流程不受系统缓存影响。
