# App 当前交互说明

本文记录 ListenBook 手机端已经生效的页面行为，作为 UI 开发和真机回归的现行基线。产品与内容架构以 [`CLAUDE.md`](../CLAUDE.md) 为准，服务端接口与部署以 [`server/README.md`](../server/README.md) 为准。

## 主框架

- 底部四个 Tab 为“首页 / 书架 / 记录 / 我的”。
- 单击 Tab 切换页面；在 300ms 内双击当前 Tab，页面滚动到顶部。
- 首页双击 Tab 不再刷新数据。首页刷新只通过下拉手势触发。
- 播放中显示底部迷你播放器，并与浮动 Tab 栏共同避让页面内容；小圆封面保持静止，外圈展示当前集收听进度。完整播放页封面同样保持静止。

## App 使用教程

从首页搜索或浏览推荐后，点击书卡进入详情页，再从章节列表选择内容。在线音频点击播放即可开始收听，底部迷你播放栏可展开，点击标题区域进入完整播放页；书架中的电子书会直接进入正文并恢复上次阅读位置。

- 首页回到顶部后下拉可刷新推荐和分类；双击当前底部 Tab 可回顶，首页双击只回顶，不触发重新加载。
- 播放页支持章节切换、`0.5x-3.0x` 倍速、片头/片尾跳过和 `15/30/45/60` 分钟睡眠定时。开启“章节结束后停止”后，定时到达时会尽量播完当前章节再暂停；长按倍速、跳过、定时分别恢复默认、清除设置和取消定时。
- 阅读页点击正文中央显示或隐藏“详情 / 章节 / 设置”，左右区域翻页；设置面板可以调整字号、行高、翻页方式、主题、底色和背景图案，修改自动保存。
- 在“我的 → 书源”点击加号导入本地 JSON、粘贴 JSON 或 HTTP(S) 地址。导入后先测试，关闭“参与搜索”只影响新搜索，不影响已有收藏解析；需要登录的来源从对应登录入口进入。
- 下载管理只显示完整下载内容；在线系统缓存不等同于离线下载。已完成章节可通过系统文件选择器导出，导出副本后可在文件管理中使用。

完整的操作分区和回归清单见 App 内“我的 → 使用说明”以及下方各章节。

## 首页

### 顶部区域

- 顶栏采用浮层 + 滚动驱动：列表占位高度固定，搜索折叠量 = clamp(scrollY, 0, 搜索行高)，一次滑动丝滑收起/展开。
- 分类标签在搜索收起后保持吸顶。
- 状态栏区域单独一条窄条：与首页底色同色半透明（`HomeTheme.StatusScrim`）+ `backdropBlur`；不延伸到搜索框和分类标签。
- 仅列表回到顶部（搜索完全展开）后下拉刷新；首页搜索框是进入独立搜索页的入口。
- 未进入搜索页时，搜索框下方显示单行横向分类标签；“推荐”及所有分类都可横向滚动访问。

### 首次加载

- 首次进入“推荐”且尚无板块数据时，在固定顶栏下方显示两组书籍板块骨架。
- 骨架使用明暗呼吸动画，不显示“加载推荐中”文字，也不叠加居中的加载圈。
- 分类首次加载和搜索加载仍可使用加载圈，但颜色必须来自 `AppColor.Brand`。

### 下拉刷新

- “推荐”和具体分类页面支持下拉刷新；独立搜索页面不启用下拉刷新。
- 刷新指示器放在分类标签与内容列表之间的下拉空白区，不使用系统默认顶栏指示器。
- 指示器使用项目橙色 `AppColor.Brand`。
- 刷新过程中保留现有内容，数据返回后整体替换，减少空白闪烁。
- 无论请求成功或失败，都必须在结束时清除 `isRefreshing` 和刷新状态，让指示器立即消失。

### 独立搜索页

- 首页点击搜索入口后进入 `SearchPage`，使用独立导航栈页面承载输入和结果。
- 搜索页不显示独立的“搜索”标题；返回按钮与搜索框位于同一行，结果工具栏的网格 / 列表按钮保持固定尺寸并垂直居中。
- 搜索框下方默认显示“搜索推荐”，推荐词可直接点击提交；清空输入后回到推荐区。
- 提交后显示“全部 / 有声书 / 电子书”结果数量和网格 / 列表切换，仍按 `sourceUrl + bookUrl` 去重。
- 未开始搜索时，历史关键词使用可换行的磨砂小标签，删除按钮保留独立空间并使用红色图标；下方直接列出从启用书源真实返回、去重后随机抽取的 5 本推荐书籍，不再展示静态分类词。
- 网格和列表结果均预留浮动底栏与系统手势区安全空间，最后一项可完整滚动到可视区域。
- 搜索框、推荐词、分段控件和视图切换使用原生沉浸光感材质；页面导航栏使用 HDS 沉浸渐变模糊，底色保持透明以适配深浅色。

### 推荐板块

- 第一个板块紧接顶部分类区域，不再叠加额外顶距；板块之间采用紧凑的垂直节奏。
- 每个板块标题右侧都显示“更多”入口，进入 `BlockMorePage` 查看对应分类的后续内容。
- 第一个板块采用每屏纵向 3 条的紧凑书籍列表，整屏可向右滑动浏览下一组，并在右侧露出下一组封面作为滑动提示。
- 后续板块根据来源配置使用横向封面列表或纵向书籍列表，网格与推荐封面统一为带小圆角的正方形。

## 书卡到详情页转场

- 首页分类、推荐封面、更多页和搜索网格中的 `BookCard` 使用 Navigation 高级一镜到底转场：点击时测量并抓取封面快照，详情页表面从源书卡连续展开，封面同步移动到详情页目标位置。
- 返回时重新测量书卡位置，将详情页收回当前源封面；窗口尺寸发生变化或源节点不可测量时使用淡出降级，避免动画错位。
- 详情页命中搜索缓存时立即渲染已有书籍信息，并在后台刷新数据，保证目标封面可参与首帧转场。
- 收听记录、下载、播放器等不提供源封面节点的入口继续使用原有详情页转场，不创建无效快照。

## 收听记录

- 页面上半部分显示累计时长、连续天数等统计摘要，下方为“收听历史”。
- 标题右侧“编辑”进入批量管理；长按任意记录也可进入多选并选中该项。
- 编辑模式提供“全选 / 删除 / 取消”，删除前需确认。
- 单条记录右侧不显示三点菜单，避免与顶部编辑功能重复。
- 普通模式下点击记录主体进入书籍详情，点击右侧播放按钮从记录位置继续播放。

## 主题与加载

- 项目品牌色统一通过 `entry/src/main/ets/theme/Theme.ets` 中的 `AppColor.Brand` 获取。
- 浅色主题的 `app_brand` 当前为 `#FF6B3D`；深浅模式都应读取资源，不在页面内复制颜色值。
- 新增或修改 `LoadingProgress` 时必须显式设置 `.color(AppColor.Brand)`，避免出现 HarmonyOS 默认蓝色。
- HarmonyOS 7 需要材质层次的悬浮控件使用 `AppMaterial.InteractiveThin`，播放器弹层和配置 Sheet 使用 `AppMaterial.SurfaceRegular`。
- 首页搜索入口和独立搜索页搜索框使用透明无赋色的原生沉浸光感材质，分类标签和搜索页控件使用 `AppMaterial.InteractiveThin`；不注入品牌底色、不叠加底部阴影，仅选中状态的文字和下划线使用主题色。首页搜索入口支持滚动折叠，分类标签吸顶。

## 播放器与系统控制

- 播放页、书籍详情页和设置页共用窗口断点；窗口高度低于 760vp 或宽度低于 360vp 时切换紧凑布局。播放页缩小封面与纵向间距并允许纵向滚动，详情页压缩顶部封面区，设置页收紧页边距和分组间距。
- 锁屏和控制中心媒体卡片显示倍速、上一集、下一集和收藏控件；最左侧为倍速，不显示循环模式。
- 系统卡片切换倍速后会调用 `AudioService.setSpeed()`，操作结果与播放器页面状态双向同步。
- 播放页底部“投播”调用 HarmonyOS 系统设备选择器；只对已解析出的 HTTP(S) 音频地址启用 URL 投播，连接远端成功后从当前进度起播并暂停本机播放器。
- 在线章节边播边使用 HarmonyOS 系统托管缓存；已完整下载或本地导入的章节仍从沙箱文件播放。
- 系统托管缓存不是“已下载章节”，不出现在下载管理页；需要长期离线保留时仍使用章节下载功能。

## 小说阅读

- 小说正文避让顶部状态栏和底部手势区，文字不进入系统安全区域。
- 进入小说正文后默认保持沉浸全屏，底部不固定显示导航；点击正文中央区域可显示或再次隐藏“详情 / 章节 / 设置”三项沉浸悬浮栏，左右区域保留给翻页。章节与设置子弹窗打开期间悬浮栏保持显示，并浮在弹窗内容上方。
- “详情”进入现有书籍详情页；“章节”和“设置”以播放器同款底部子弹窗覆盖在正文上，不再切换到全屏子页面。章节弹窗打开时自动居中定位当前章节，滚远后显示“回到当前章节”。
- 书架中的电子书点击后直接进入阅读页，并从本地阅读进度恢复章节与页内位置，不再先重复进入详情页。
- 从小窗直接启动或在小窗与全屏之间切换时，底部悬浮栏会读取普通导航区与小窗导航区，并在窗口状态切换完成后重新计算底部间距。

### 阅读设置面板

- 设置弹窗按鸿蒙分组卡片排布：顶部实时预览卡，下接「字号 / 行高 / 阅读主题 / 自定义底色 / 背景图案」五张卡。不使用裸滑杆堆叠。
- 预览卡用真实字号、行高、底色与纹理渲染样例段落，调任何一项都立即反映；面板自身底色也跟随当前阅读配色，不需要关掉面板才能看效果。
- 字号：左右圆形步进按钮 + 滑杆，到达上下限时步进按钮置灰。行高：紧凑/适中/标准/宽松四档胶囊 + 滑杆微调，两者双向同步。
- 阅读主题：羊皮纸 / 护眼绿 / 纯白 / 夜间 / 纯黑五个预设，外加一个显示当前自定义色的「自定义」色板，选中态描边并打勾。
- 自定义底色：色相 / 浓淡 / 明度三滑杆实时合成色值并显示 hex。正文色不单独设置，由底色亮度自动配对（浅底深字、深底浅字），且不使用纯黑纯白避免高对比刺眼。
- 背景图案：无 / 纸纹 / 布纹 / 相册四选一。纸纹与布纹是程序化渐变，随底色变化，不占用图片资源。选相册时拉起系统选图并复制进沙箱 `files/reader_bg`，额外露出蒙层浓度滑杆保证正文可读；换图后自动删除上一张。
- 深色主题（夜间 / 纯黑 / 深色自定义底）下状态栏字色自动切换为白色。
- 拖动滑杆过程中只重排不写盘，松手或点击才持久化；「恢复默认」一键回到出厂配置。
- 字号、行高、主题、自定义底色、图案、图片路径与蒙层浓度全部持久化，重进阅读页保持上次设置。声明了相册图案但图片路径已失效时自动退回无图案。

## 书源管理

- “我的”页原服务器地址区域改为“书源”入口，与“设置”处于同一导航层级；设置页不再重复展示书源入口。书源页可通过系统文件选择器读取本地 `.json`，也可粘贴单个书源 JSON、书源数组、常见列表外壳或 HTTP(S) 导入地址。
- 已安装书源存在时，页面默认优先展示管理列表，导入面板通过标题栏加号按需展开；没有已安装书源时自动展开导入面板。
- 顶部搜索框按名称、来源地址和分组实时过滤；状态、内容类型和启用状态可组合筛选，列表摘要同时显示当前结果数与已安装总数，筛选无结果时使用独立空态。
- 管理列表始终将听书书源排在其他书源前面，同类型内保持原导入顺序；多个分组使用紧凑标签展示，数组和对象格式的导入分组会先标准化，旧的 `[object Object]` 占位不会显示。
- 标题栏“编辑”进入批量管理；全选和取消全选只作用于进入编辑时的当前搜索、筛选结果，选择集合不进入响应式状态，批量启停和删除按 400 条分块写入同一事务，任一记录失败时整批回滚，并清理对应登录会话和 Cookie。
- 导入区下方显示已安装数量和搜索测试关键词；每个来源卡片展示名称、文本/音频类型、来源地址、兼容状态及具体原因。
- 状态包括“待测试 / 可用 / 测试失败 / 暂不兼容”。搜索测试只作用于当前来源，结果会写回状态，不会阻断其他来源。
- “参与搜索”开关只控制新搜索聚合。来源关闭后，只要仍安装且兼容，书架中依赖该来源的详情、目录、正文和音频解析仍可继续使用。
- 卡片底部使用单排图标按钮，按能力依次提供书源测试、主书源账号、子书源和删除；按钮使用固定尺寸，窄屏下不得挤压或换成说明文字。
- 原生聚合源可进入子书源页，按全部、小说、听书筛选并按名称检索。页面先展示适配器内置目录，再用现有搜索接口刷新本次发现状态、结果数和响应耗时；接口失败不能清空目录。
- 需要网页账号且已配置官方入口的子源显示“登录”，按子源进入 App 内嵌 HTTPS 页面，不得跳到聚合服务账号页。登录页使用 ArkWeb 隐私模式，展示当前书源和 origin；退出时把 Cookie 写入 S2 加密的 `source_url + origin` 隔离记录并清空 Web 会话，后续本地规则直连同一 origin 时复用该 Cookie。
- 结构化规则和 `@{...}` 紧凑规则均可导入；规则字段中的 `@js` 和来源级 `jsLib` 由受限 QuickJS 兼容运行时处理。通用脚本登录 / 登录 UI、漫画、未知类型或无法解析紧凑搜索规则的来源仍会显示“暂不兼容”。
- 聚合源同时保留主书源账号和子书源登录。光遇主账号使用原生邮箱/密码表单调用官方 `/login_api`，只保存返回的 `qttoken`、稳定 `deviceId` 和账号标签；子书源仍在 App 内 ArkWeb 登录，并按 `source_url + origin` 独立保存各站点 Cookie，二者不得互相替代。
- 删除来源前必须确认，并提示依赖该来源的收藏可能无法继续加载；删除会同步清除该来源会话和 Cookie，本地规则失败不得改变欢FM及既有文本源的正常行为。
- 本地规则源只进入搜索、详情、目录、正文和音频链路，不进入首页推荐、分类和“更多”板块。

## 系统备份与跨设备续播

- 系统备份使用 `files/backup/listenbook_state.json` 白名单快照，包含在线收藏、历史、进度、跳过设置、收听统计、在线书元数据、通用设置和清洗后的本地书源规则字段。
- 华为账号标识、卡片 ID、缓存音频、离线下载、本地导入路径，以及书源实际登录会话、Cookie、敏感 Header Token 和原始书源 JSON 不进入系统备份；`jsLib`、来源变量和登录规则定义随清洗后的可执行定义迁移，恢复后状态回到“待测试”。
- EntryAbility 支持跨设备迁移；当前在线书、章节、原始章节地址、进度、时长、倍速和播放状态通过最小载荷迁移，目标设备恢复后进入播放页并按原状态续播。
- 迁移载荷不携带完整章节目录；目标设备先恢复当前章节，进入页面后再按来源补齐完整目录。

## 下载管理与文件导出

- 每本存在已完成下载章节的书显示“导出”按钮；进行中的章节不会进入导出列表。
- 点击“导出”后打开 HarmonyOS 系统文件保存界面，用户选择文件管理中的目标位置，App 按章节顺序复制音频副本。
- 导出文件使用四位章节序号和清理过的章节标题命名；导出完成后提示成功与失败数量，取消系统选择器不显示错误。
- 私有下载原件继续保存在应用沙箱，文件管理中得到的是用户主动导出的副本；普通应用不会也不能把整个私有沙箱直接暴露给文件管理。

## UI 回归清单

1. 清除或首次启动首页数据后，确认推荐区显示骨架屏且没有“加载推荐中”。
2. 在推荐页下拉，确认橙色指示器位于分类栏与列表之间，松手后完成刷新并消失。
3. 切换到具体分类后重复下拉检查；从首页进入搜索页后确认推荐词、搜索提交和结果页不触发下拉刷新。
4. 确认第一个推荐板块每屏显示 3 条、右侧露出下一组封面且可向右滑动，后续推荐封面为圆角正方形；同时检查首板块紧接分类栏且每个板块都有“更多”入口。
5. 在四个 Tab 分别滚动后双击当前 Tab，确认只回到顶部，不触发首页重新加载。
6. 在记录页分别验证“编辑”和长按进入多选、全选、取消、确认删除及继续播放。
7. 检查首页、更多页、详情页等可见加载圈均为项目橙色，不出现系统默认蓝色。
8. 在 HarmonyOS 7 真机检查首页顶部与列表颜色一致，并确认首页入口、搜索页输入框、推荐词和分类控件的沉浸光感；上滑时首页搜索入口折叠、分类标签吸顶，回顶后下拉可展开入口。
9. 打开播放器的章节、定时、跳过和倍速弹层，确认材质、圆角、阴影和关闭手势正常且无内容重叠。
10. 播放、暂停、拖动进度并切换章节，确认底部迷你播放栏的小圆封面保持静止，外圈按当前集进度更新并在换集后重置；完整播放页封面不旋转。
11. 打开锁屏或控制中心媒体卡片，确认最左侧显示倍速而非循环模式；切换倍速后检查播放器页面数值同步，再验证上一集、下一集和收藏。
12. 连续播放同一在线章节两次，确认播放正常；再下载章节，确认下载管理与本地播放流程不受系统缓存影响。
13. 在下载管理页导出一本含多个已下载章节的书，确认系统文件保存界面可选择目标位置、文件名按章节排序、导出副本可在文件管理中打开，且取消选择不会报错。
14. 将播放页切换为小窗并连续调整窗口尺寸，确认封面保持正方形、进度与播放控制不会被裁切；在极窄或极矮尺寸下可纵向滚动访问全部功能。
15. 在相同小窗尺寸打开书籍详情和设置页，确认顶部信息、设置分组完整可见且间距同步收紧。
16. 播放在线章节后点击“投播”，确认系统设备选择器正常打开；连接远端后从当前进度播放且本机暂停，本地导入内容显示不可投播提示。
17. 通过系统备份恢复后，确认在线收藏、历史、进度、跳过设置、统计、通用设置及含 `jsLib` / 来源变量的本地书源可执行定义恢复，来源状态回到“待测试”；同时确认账号、下载、本地导入内容、书源实际登录会话、Cookie、敏感 Header Token 和原始 JSON 没有被迁移。
18. 在两台设备间迁移播放任务，确认目标设备进入播放页、恢复章节/进度/倍速，并在源设备原本播放时自动续播。
19. 打开小说正文，确认文字不进入状态栏和底部手势区且悬浮栏默认隐藏；点击正文中央区域可显示、再次点击可隐藏“详情 / 章节 / 设置”，左右区域仍可翻页；确认章节与设置从底部弹出且不替换正文，章节打开即定位当前章、滚远后可一键返回；再从书架点击电子书确认直接恢复阅读。在 App 进程未启动时直接以小窗拉起，再放大到全屏，确认主页面和阅读页底部悬浮栏在两种窗口状态下都保持安全距离。
19b. 打开阅读设置面板，逐项验证：预览卡随字号/行高/主题/图案实时变化；字号到上下限时步进按钮置灰；行高四档胶囊与滑杆双向同步；切换五个预设主题与自定义底色时正文、页眉页脚、章节弹窗和面板本身同步换色；深色主题下状态栏字色转白；选相册图后蒙层滑杆出现且能压住图片保证正文可读；「恢复默认」一键还原。退出阅读页再进入，确认全部设置保持；手动删除沙箱背景图后重进应自动退回无图案而不是空白背景。
20. 从首页分类、推荐封面、更多页和搜索网格点击书卡，确认封面连续移动到详情页、页面从书卡位置展开，返回时沿原路径收回且没有闪白、黑屏或双封面跳变。
21. 进入详情后改变窗口尺寸再返回，确认自动使用淡出降级而非飞向旧坐标；源书卡被滚出可视区时也不应出现明显错位。
22. 从收听记录、下载管理和播放器进入详情，确认无源节点入口仍能正常进出，不受一镜到底转场影响。
23. 未导入任何本地书源时，验证欢FM和既有文本源的搜索、详情、目录、阅读与播放行为和改造前一致，并确认 App 不再注册 `jianhu_server`。
24. 从“我的 → 书源”分别选择本地 `.json`、粘贴有效 JSON 和填写 HTTP(S) 导入地址，确认导入完成后显示稳定的来源数量、类型、地址、“待测试”状态及兼容原因；设置页不得出现重复入口。
25. 修改搜索测试关键词并逐个测试来源，确认成功和失败只更新当前卡片；一个来源超时、零结果或解析失败时，其他来源仍能完成搜索。
26. 分别导入结构化规则、`@{...}` 紧凑规则和包含 `@js` / `jsLib` 的来源，确认可进入待测试状态；通用脚本登录、漫画、未知类型或无法解析紧凑搜索规则的来源仍应显示“暂不兼容”和具体原因。
27. 对文本规则源验证“搜索 → 详情 → 目录 → 正文阅读”，对音频规则源验证“搜索 → 详情 → 目录 → 播放”，并确认 Header、Cookie、`@put` / `@get` 变量和章节来源地址可沿链路传递；脚本超时或网络动作超出预算时应明确失败且不影响其他来源。
28. 将已收藏来源的“参与搜索”开关关闭，确认新搜索不再出现该来源，但从书架进入原收藏仍可加载详情、正文或音频；重新打开后恢复参与搜索。
29. 删除一个已收藏书依赖的来源，确认页面给出风险提示且后续解析以明确错误结束、不闪退；随后复测欢FM和其他本地来源均不受影响，重新导入同 URL 来源时不得恢复已删除 Cookie。
30. 导入“光遇聚合”后确认不再显示“暂不兼容”；主账号按钮应打开原生邮箱/密码表单并通过官方 `/login_api` 登录。书源测试应同时确认小说/听书搜索并只执行一次听书完整链路，避免触发普通账号 `3 次/30 秒` 限流；遇到业务限流必须立即停止重试并显示明确提示。登录后搜索、详情、目录、正文和音频均携带同一主会话，切换 `v1` 至 `v7` 线路仍能访问；退出或删除来源后 token 被清除，备份不包含 token、Cookie 和密码。
31. 在书山聚合和光遇聚合卡片进入“子书源”，确认可筛选、搜索和刷新；断网时仍保留内置目录。点击需要登录的子源应进入 App 内对应白名单站点，不得打开聚合账号页；完成后确认 Cookie 写入该书源与站点的隔离记录，另一个书源登录同域时不得读到该记录。
