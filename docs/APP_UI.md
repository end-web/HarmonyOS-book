# App 当前交互说明

本文记录当前手机端页面行为，作为 UI 开发与真机回归基线。架构和数据说明见 [CLAUDE.md](../CLAUDE.md)，服务端说明见 [server/README.md](../server/README.md)。这里的回归清单是验证要求，不代表每项已在当前设备执行。

## 主框架与导航

- 底部四个 Tab 为“首页 / 书架 / 记录 / 我的”。单击切换，在 300ms 内双击当前 Tab 回到该页顶部；首页双击只回顶。
- `Index` 使用 `NavPathStack` 集中管理搜索、详情、阅读、播放、下载、导入、书源、账号、设置等路由。
- 底部迷你播放器与浮动 Tab 栏共同避让内容和系统手势区。小圆封面保持静止，外圈展示当前集进度；完整播放页封面同样不旋转。
- 普通窗口、小窗和窗口切换后的安全间距由 `WindowUtils` 更新。

## 首页

- 推荐和分类依赖已导入且启用的听友来源；未找到可用来源时显示相应空态或提示。
- 顶部搜索入口随滚动折叠，分类栏保持吸顶。状态栏使用与页面底色一致的半透明遮罩和模糊。
- 首页搜索框用于进入独立搜索页，不在首页直接承载搜索结果。
- 首次加载且无板块数据时显示两组呼吸骨架，不叠加居中加载圈或“加载推荐中”。
- 搜索入口完全展开且列表在顶部时可下拉刷新。推荐和分类刷新保留旧内容，结束时清除刷新状态。
- 刷新指示器位于分类栏和内容之间，使用 `AppColor.Brand`。
- 每个推荐板块有“更多”入口。第一个板块每组纵向显示 3 条、横向滑动，右侧露出下一组；后续板块按来源布局显示，封面统一为圆角正方形。

## 搜索

- 返回按钮与搜索框同一行，不额外显示页面标题；返回、输入和结果视图控制使用稳定尺寸。
- 未搜索或清空输入时显示搜索历史与推荐书籍；没有来源或未取到推荐时显示空态。
- 推荐区直接显示启用来源真实返回的书籍，去重随机抽取最多 5 本。优先尝试首页内容，不足时通过来源搜索补充。
- 搜索历史是可换行的磨砂标签，最多保存 20 条；重复关键词移到最前。点击标签重新搜索，红色删除图标拥有独立点击区域，“清空”删除全部历史。
- 提交后按每批最多 6 个导入源并行搜索，逐步展示结果；按 `sourceUrl + bookUrl` 去重，连续搜索时丢弃旧请求结果。
- 结果提供“全部 / 有声书 / 电子书”计数与网格/列表切换。单源失败不阻断其他来源。
- 搜索页不启用下拉刷新，结果末项可完整滚动到浮动底栏和系统手势区上方。
- 输入、历史标签和结果控件使用沉浸材质，导航区保持透明并使用渐变模糊。

## 书架与收听记录

- 书架支持内容类型筛选及网格/列表视图，长按书籍可拖到删除区。删除本地内容时按弹窗选择是否删除文件。
- 书架电子书直接进入正文并恢复位置；音频书按对应入口继续收听或查看详情。
- 记录主页展示统计摘要及已收藏书的收听记录，“未收藏历史”使用独立页面查看未收藏书记录。
- 顶部“编辑”或长按记录进入多选，提供全选、删除、取消；删除前确认。
- 普通模式点击记录主体进入详情，点击右侧播放按钮从上次位置继续；单条记录不重复显示三点菜单。

## 详情与转场

- 首页、更多页和搜索页书卡提供封面位置与快照，用于书卡展开到详情页、返回收回的连续转场。
- 详情先使用书籍缓存展示，再刷新数据。窗口尺寸或源书卡位置失效时降级，避免飞向旧坐标。
- 记录、下载和播放器等无源书卡节点的入口使用普通详情转场。
- 播放页、详情和设置使用共用窗口断点；高度低于 760vp 或宽度低于 360vp 时收紧布局。播放页允许纵向滚动访问全部控件。

## 播放与定时

- 播放页支持章节选择、进度拖动、0.5x–3.0x 倍速和片头片尾跳过；按书籍、章节保存进度。
- 章节、倍速、跳过和定时使用底部弹层。长按倍速恢复 1.0x，长按跳过清除设置，长按定时取消。
- 定时预设为 15/30/45/60 分钟，可打开“章节结束后停止”。
- 到时仍在播放且本章剩余时长大于 0、不超过 10 分钟时，智能停止等待本章结束；剩余时长超限、无效或未在播放时直接暂停。当前没有渐弱淡出功能入口。
- 锁屏和控制中心媒体卡片提供倍速、上一集、下一集和收藏，最左侧为倍速；倍速与 App 双向同步。
- “投播”打开系统设备选择器，仅对已解析的 HTTP(S) 音频地址启用 URL 投播。连接远端后从当前进度起播并暂停本机。
- 在线音频使用系统托管缓存；本地导入与已下载章节从沙箱文件播放。系统缓存不作为已下载章节列入下载管理。

## 小说阅读

- 在线小说经 `BookSourceService` 获取正文，用 `OnlineTextPaginator` 分页；保存章节与字符位置，字号或窗口变化后重新分页。
- 正文避让状态栏和手势区。默认隐藏“详情 / 章节 / 设置”悬浮栏；点击中央显示或隐藏，左右区域用于翻页。
- “详情”进入书籍详情；章节和设置以底部弹窗覆盖正文。子弹窗打开时悬浮栏保持显示。
- 目录打开时定位当前章节，滚远后可“回到当前章节”。
- 小窗直接启动及全屏/小窗切换后重新计算安全距离。
- 阅读页保留已有 EPUB 文件路径的 ReaderKit 分支，但文件导入页只处理音频和音频 ZIP；不能把它描述为已完成本地 EPUB 导入和书签管理。

### 阅读设置

- 设置面板包含实时预览、字号、行高、翻页方式、主题、自定义底色和背景图案。
- 字号采用步进按钮与滑杆，到达边界时禁用对应按钮；行高预设档位与滑杆同步。
- 主题包括羊皮纸、护眼绿、纯白、夜间、纯黑以及自定义色；正文颜色根据背景亮度配对。
- 自定义底色通过色相、浓淡、明度调节，预览和面板同步更新，深色背景下切换状态栏文字颜色。
- 图案可选无、纸纹、布纹、相册；相册图片复制到 `files/reader_bg`，可调蒙层浓度，换图清理上一张。
- 拖动时更新预览，结束或点击后持久化；恢复默认重置设置。背景图片失效时退回无图案。
- 阅读位置和设置使用独立 Preferences 保存，不是电子书 RDB 或当前系统备份快照的一部分。

## 书源管理与测试

- 入口为“我的 → 书源”，与设置同级。已有来源时优先展示列表，标题栏加号展开导入；无来源时自动展开导入区。
- 支持本地 JSON、粘贴单源/数组/列表外壳和 HTTP(S) 地址。导入后显示“待测试”和能力提示。
- 搜索框按名称、地址、分组过滤；听书来源优先，其余保留相对顺序。摘要显示匹配数/总数。当前没有独立状态、类型、启用状态筛选控件。
- “编辑”进入批量管理，全选作用于当前搜索结果；可批量启用、停用和删除。删除需确认，同时清除对应主会话和 Cookie。
- 来源卡片展示名称、类型、分组、地址、测试状态和诊断原因；底部图标按能力提供测试、主账号、网站登录、子源和删除。
- “参与搜索”按启用开关和必需搜索规则决定是否加入新搜索，测试状态不直接禁止启用。关闭后保留定义，已有收藏仍可解析。
- 页面测试使用固定关键词“我的”，不提供可编辑测试关键词输入框。
- 单源测试有结果时继续验证详情、目录与正文/音频；普通来源正常请求但暂无匹配时保留来源并说明，不能把它当作完整内容链通过。
- 批量测试针对全部已安装来源，确认后最多同时运行 6 个搜索探测，展示总数、完成、通过、失败与保留数量；不自动删除失败来源，也不修改启用状态。
- 来源需要主账号但尚未登录时，单源测试或批量测试准备阶段会转入账号页。
- 导入保留脚本登录定义、类型和紧凑规则能力提示；当前不会仅因这些字段标记整源不可执行。仍须在实际请求阶段验证兼容性，非音频类型尝试文本链不代表支持漫画阅读。

### 主账号与子源登录

- 光遇和书山主账号使用原生账号页，通过 `RuleSourceAccountService` 调用专用账号服务。
- 光遇单源测试要求小说与听书搜索覆盖，只执行一次听书内容链验证；遇业务限流应停止内容候选重试并显示原因。书山测试验证小说和听书内容链。
- 聚合来源的子源页提供全部/小说/听书筛选、名称检索和状态刷新；先显示适配器目录，请求失败保留已有目录。
- 主会话与子源网站 Cookie 分开保存。子源登录进入相应官方白名单 HTTPS 页面，普通来源可使用其 HTTPS 登录地址。
- 网页登录使用隐私 WebView，不暴露平台桥接，按来源和 origin 注入与回收 Cookie；退出时写回 S2 加密数据库并清理 Web 会话。
- 删除来源清除主会话与 Cookie；同 URL 重导保留尚未删除来源的登录态，删除后重导不恢复已清除凭据。

## 下载与导出

- 已完成下载的章节可以导出，进行中章节不在导出集合内。
- 导出调用系统文件保存选择器，按章节顺序复制音频，文件名使用四位序号和清理后的章节标题。
- 完成后报告成功/失败数，取消选择不报错；沙箱原件继续保留，文件管理中得到副本。
- 文件导入页支持音频和音频 ZIP，可设置书籍信息与封面。

## 系统备份与跨设备续播

- 系统备份使用 `files/backup/listenbook_state.json` 白名单，包含在线收藏、收听历史、播放进度、跳过设置、统计、在线书元数据、通用设置和清洗后的书源定义。
- 实际账号会话、Cookie、敏感 Header Token、原始书源 JSON、卡片 ID、缓存音频、下载、本地导入路径不进入快照；独立阅读位置和阅读设置也不在当前快照中。
- 清洗后的 `jsLib`、变量和登录规则定义可随来源迁移，恢复后状态回到“待测试”。
- 跨设备续播传递当前在线书、章节、原始章节地址、进度、时长、倍速和播放状态；目标设备先恢复当前章节，再补齐完整目录。

## 主题与加载

- 主题读取 `AppColor` / `AppMaterial`，不在页面复制品牌值。浅色 `app_brand` 为 `#FF6B3D`。
- 所有新增或修改的 `LoadingProgress` 显式设置 `.color(AppColor.Brand)`。
- 交互浮层使用 `AppMaterial.InteractiveThin`，播放器和配置弹层使用 `AppMaterial.SurfaceRegular`。
- 首页入口和搜索输入使用透明原生沉浸光感材质，选中文字与下划线使用主题色。

## 回归清单

1. 无导入源时首页、搜索推荐和管理页显示相应空态；导入并启用听友来源后可加载首页和分类。
2. 首页首屏骨架、首板块三条横滑、后续封面和“更多”正常；下拉指示器在分类栏下方，成功和失败后均消失。
3. 搜索入口滚动折叠、分类吸顶，四个 Tab 双击只回顶；窄屏和大字体下控件不重叠。
4. 搜索历史最多 20 条、重复词前移、单删/清空正常；推荐来自真实书籍，没有来源时不显示虚构推荐。
5. 连续提交不同关键词不会混入旧结果；类型计数、网格/列表切换、来源去重和单源失败隔离正常。
6. 书架电子书直接恢复阅读；记录主页与未收藏历史分开显示，编辑、长按、全选、取消、确认删除及继续播放正常。
7. 书卡进出详情转场连续；窗口变化或源卡不可见时降级，无源卡入口也能正常进出。
8. 播放、暂停、拖动、切章和续播正常；两处封面静止，迷你进度圆环在换集后更新。
9. 倍速、跳过、章节和定时弹层可操作；智能定时分别验证剩余不足 10 分钟、超限和暂停状态。
10. 系统卡片倍速、上下集、收藏与 App 同步；在线 URL 投播连接后恢复进度并暂停本机。
11. 在线系统缓存、主动下载和本地导入分别可用；多章导出顺序正确，取消选择无错误，导出文件可打开。
12. 在线小说跨章、退出重进恢复字符位置；改变字号、行高和窗口尺寸后位置合理，章节定位与预取正常。
13. 阅读工具栏和弹层不遮挡正文；小窗冷启动、全屏切换、深浅色状态栏与安全区正常。
14. 阅读设置预览与正文同步，退出重进保持配置；失效背景图降级，恢复默认正常。
15. 本地 JSON、粘贴 JSON、HTTP(S) 导入成功；重导、名称/地址/分组检索、听书排序和空结果正常。
16. 单源测试和批量搜索测试展示不同验证范围；批量失败保留来源和启用状态，其他任务继续完成。
17. 测试状态和能力提示不错误锁死开关；禁用后收藏可解析，删除后明确报错而不闪退。
18. 批量启停与删除只作用于选中来源；确认删除后会话和 Cookie 清理，同 URL 重导不复活已删凭据。
19. 光遇、书山主账号登录与测试正常；子源筛选、刷新和 HTTPS 登录按来源/origin 隔离，断网保留目录。
20. 带 Header、Cookie、变量、紧凑规则和 QuickJS 的来源完成搜索到阅读/播放；脚本超时不阻断其他来源。
21. 系统恢复仅还原白名单，来源待测试；敏感会话与本地文件不迁移。两台设备间续播恢复章节、位置、倍速和播放状态。
22. 全部加载圈使用品牌色；播放器、详情、设置在小窗与紧凑尺寸下可完整访问。
