# 简听 v0.1.47 更新说明

日期：2026-10-08。版本：0.1.47 / 1000047，最低 HarmonyOS 6.0（API 20），目标 API 26。

## 首页与详情

- 封面转场绑定实际点击的卡片实例，同一本书在轮播和书单重复出现时，进入与返回各自对应原位置。
- 推荐板块分批插入后按当前板块身份判断首板块，避免旧序号让多个板块共用首板块轮播。
- 点击使用有 80ms 上限的异步封面截图；按包含祖先绘制变换的窗口坐标定位，截图完成后重新测量起点。
- 保持进入 420ms、返回 350ms，请求设备支持的 60–120Hz；进入时停止绘制首页，不对两整页进行交叉淡化或创建临时整页合成层。
- 详情交接不等待网络封面加载。背景和标签材质分帧恢复，仅独立氛围层缓慢显现；缓存目录 JSON 移入 taskpool 解析。

## 书源导出

- 使用紧凑 JSON，未修改的字段保留原始形式，不补入默认字段与空规则组。
- 保留实际编辑、未知扩展字段与管理状态；测试诊断和登录会话不进入导出文件。

## 构建与验证

- 转场修复已在 VYG-AL00 实测：同一本“十日终焉”的轮播与书单分别进入、返回原位置；完成“剑来”进入与返回的帧追踪。采样不代表所有设备和场景均无掉帧。
- 重复书籍入口、坐标与快照生命周期回归通过；本地导入/目录缓存回归通过；书源导出稳定往返、编辑和会话剔除回归通过。
- v0.1.47 开发者 HAP 使用 debug 模式和调试签名，开启仅限 debug 的开发者权益；邀测 APP 使用 release 模式，开发者开关关闭，采用正式发布签名与 app_gallery Profile。
- 两个产物使用 Release SDK 26.0.0.105，并通过包元数据和 SDK 签名工具核验。文件、SHA-256 和核验记录位于 artifacts/releases/v0.1.47/。
- 本次生成本地邀测包，未上传 AppGallery Connect 或发起邀测。
