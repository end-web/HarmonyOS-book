# 简听 v0.1.34 邀测更新说明

## 本次更新

- “我的 → 支持与联系”新增“主题图标(限免)”，提供八款主题及默认图标恢复；主体放大并按视觉重心居中，磨砂玻璃使用独立新版设计。
- API 26 起支持直接切换桌面图标；API 20–25 展示预览和升级提示。
- 搜索增加电子书、有声书类型筛选，优化选项菜单及本机设置保存。
- 书架支持置顶、取消置顶和顺序保存，在线书籍置顶随备份迁移。
- 书源卡片、账号页本地备份与华为云空间卡片支持折叠，优化页面布局。
- 关于页“获取更新”改为打开华为应用市场详情页，同步隐私说明。

## 版本与验证

- 版本 `0.1.34` / `1000034`，包名 `com.huan.listenbook`，最低 API 20、目标 API 26，仅支持 phone。
- 使用 Release SDK `26.0.0.105`、release 构建模式及既有发布签名生成邀测 APP。
- 定向回归：搜索并发与偏好保存、书架置顶与批量删除、阅读及本地/云备份恢复。
- 前序调试包已安装到连接的实机；本次邀测包核验不等同于完整功能实机回归。
- 包核验覆盖版本、SDK 渠道、非调试标记、发布 Profile、默认及八款 1024px 分层图标。
