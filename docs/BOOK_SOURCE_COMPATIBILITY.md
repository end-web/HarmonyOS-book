# 书源兼容性

当前解析实现统一采用轻页的固定版本源码，兼容范围由该版本决定；不再维护简听旧规则子集。支持的定义及执行入口见 [书源规则](BOOK_SOURCE_RULES.md)，版本、平台差异、回归和更新方式见 [轻页引擎同步](LIGHT_SOURCE_SYNC.md)。

搜索、发现、详情、目录、正文、图片、音频、视频和段评动作使用同一上游规则核心。简听继续维护页面、阅读/播放及数据持久化，脚本使用有界 QuickJS，Cookie按源隔离。原简听独立格式和专用内容协议解析器已删除，历史停用定义保留数据但不执行。

通过规则回归不等于每个第三方网站已完成设备登录、网页嗅探和受保护媒体验证。需要按具体书源检查实际结果，不能用导入成功或单次搜索成功替代完整阅读链。
