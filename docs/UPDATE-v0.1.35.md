# 简听 v0.1.35 邀测更新说明

## 本次更新

- 修复系统清理缓存导致书架资源丢失：在线书籍信息、章节目录、已读/预读正文和音频预缓存改存应用持久目录，升级自动迁移旧资源。迁移失败保留原文件，普通系统清缓存不再删除这些已保存资源。
- 保留应用内主动清理和音频预缓存 1GB 容量管理；书架“删除书架及本地”同时清理该书的正文和音频预缓存。清除应用数据或卸载仍会删除本地资源。
- 横屏隐藏状态栏时，为阅读页眉保留顶部最小间距，缓解无摄像头一侧页码贴近屏幕圆角的问题。
- 阅读底部手势避让与用户下边距共用留白，减少翻页模式和 ReaderKit 的重复底部空白。
- 优化播放器在可同屏显示的紧凑窗口中的底部布局。
- “图标主题(限免)”选中状态改为图标角标，调整感谢名单及展示顺序。

## 版本与验证

- 版本 `0.1.35` / `1000035`，包名 `com.huan.listenbook`，最低 API 20、目标 API 26，仅支持 phone。
- 使用 Release SDK `26.0.0.105`、release 构建模式及既有发布签名生成邀测 APP。
- APP 构建与签名校验通过，内嵌发布 Profile 为 release；包内 HAP 的版本、SDK 渠道、构建模式、非调试标记及 phone 类型正确，默认与八款主题的 18 张分层图标均为 1024px。QuickJS HAR 的 SDK 渠道为 Release。
- 定向回归通过：旧书架/目录/正文/音频迁移、迁移失败保留源文件、模拟系统清缓存后重新读取、按书清理、音频预加载与容量淘汰；阅读进度、状态栏及设置回归通过。
- 前序调试包已安装到 Mate 80。真机系统“一键清理”、Pura X View 观感及完整搜索→播放→下载导出链路尚未完成实机回归；测试目录内清理模拟不等同于真机系统清理验证。
- 升级后先打开简听完成资源迁移，再进行系统缓存清理。升级前已被删除的资源需要重新获取。
