# 搜索历史 UI 说明

## 设计样式

搜索历史采用**标签（Tag）式设计**，与搜索推荐保持一致的视觉风格。

### 布局特点

1. **标题行**：
   - 左侧："搜索历史"（粗体标题）
   - 右侧："清空"按钮（橙色强调色）

2. **历史标签**：
   - 采用 Flex 布局，自动换行
   - 每个标签为圆角胶囊形状（Pill）
   - 浅色卡片背景
   - 高度：32px
   - 内边距：左右各 12px
   - 标签间距：右侧和底部各 8px

3. **标签内容**：
   - 关键词文本（13号字体）
   - 右侧 X 图标（删除按钮）
   - X 图标区域：28x28 的独立点击区

### 交互行为

1. **点击标签**：填充关键词并执行搜索
2. **点击 X 图标**：删除该条历史记录
3. **点击"清空"**：删除所有历史记录
4. **视觉反馈**：
   - 标签点击：缩放至 0.96
   - X 图标点击：缩放至 0.9

### 技术实现

- 使用 `Stack` 组件实现标签和删除按钮的层叠
- 删除按钮使用独立的点击区域，避免事件冲突
- 历史记录通过 `PreferenceService` 持久化存储
- 最多保存 10 条历史记录

## 与推荐搜索的区别

- **推荐搜索**：纯展示标签，点击直接搜索
- **搜索历史**：带删除功能的标签，支持单条删除和全部清空
