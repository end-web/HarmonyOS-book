# 简听 v0.1.46 更新日志

日期：2026-10-08。版本：0.1.46 / 1000046，最低 HarmonyOS 6.0（API 20），目标 API 26。

## 详情与搜索

- 修复根 Navigation 封面动画与详情 NavDestination 整页淡入同时运行的问题；所有详情进入/返回统一由根导航调度，无封面快照时走同一控制器的淡入降级。真图提交后直接交接封面快照，不再追加 100ms 淡出锁定。详情遮住首页时停止绘制首页轮播和材质，保留布局及滚动位置，返回开始即恢复绘制。

- 重新组织详情页封面、书籍信息、标签和简介，支持深浅色主题与沉浸式顶栏。
- 提供加入书架/已在书架、查看目录、换源和阅听记录快捷入口，顶栏同步收藏状态。
- 目录移入独立弹层，支持搜索、正倒序、列表/分段切换及定位当前章节；返回操作优先关闭弹层。
- 底部提供阅读/听书和继续阅读/收听按钮；点击分类标签可带关键词直接进入搜索。
- 首页普通书卡改用有超时保护的异步封面截图，避免同步 GPU 回读阻塞点击；移除包住实时材质的整页离屏缓存。
- 标签和简介图标改为行内 SymbolSpan，与文字共用排版基线；六行占位放到外层容器，短简介从顶部开始。
- “标签”“简介”标题调整为 16fp 中等字重，正文保持 14fp/15fp；封面相对上一版上移 8vp。
- 保留原生 HDS 沉浸信息 Tab，详情路由及进入时的底层保持不透明，仅封面运动，固定动画裁剪圆角并请求 60fps 以减少重复合成。
- 顶部改为 104vp 内容内边距，替换会被压缩的空白占位，避免简介加载或展开后封面与返回按钮重叠。
- 固定封面占位与两行进度区，降低封面比例、阅读进度和目录回填造成的上下跳动。
- 放大标题、作者、操作文字与简介，收紧图标文字间距，底部按钮下移；简介默认展示六行，可展开或收起。

## 首页榜单

- 小说榜单以每列两本横向排列，最多展示六本，并露出下一列提示滑动。
- 完整榜单展示上限调整为 99 项，保留来源返回的实际数量。

## 导入书源兼容

- 补充空值请求头传输兼容，从书籍 URL 初始化 book_id/bookId 变量，改善依赖这些字段的接口请求。
- 完善正文净化规则、替换模板和段落处理；大载荷脚本使用最长 5 秒的受限执行预算，仍由原生中断兜底。
- 首次 DOM 解析宿主挂载等待上限由 5 秒调整为 20 秒，降低冷启动解析失败概率。
- JSON 响应中的 html/@html 返回原始文本，后接脚本保持字符串语义；显式 JSON 字段仍通过 JSONPath 获取。
- 补充音频 JSON 地址候选字段，减少非媒体链接误判，将最终响应地址纳入音频匹配，并扩展音频类型声明识别。

## 分发与验证边界

- 详情修复使用 Release SDK 构建开发者 HAP，已安装到连接的 VYG-AL00；邀测构建暂停。
- 本轮实机截图确认标签/简介行内图标对齐；修复重复转场后采样已无 NavDestination 整页透明度动画，关联自定义动画数从 18 降为 0；进一步停止绘制被遮挡首页后，最终首页书卡进入采样的 UI 首帧约 36.5ms，渲染任务平均 3.3ms、最大 11.3ms，该窗口无渲染任务超过 16.7ms；返回后可再次进入详情。首帧开销仍存在，单次采样不能视为全部场景无掉帧。60fps 为动画请求值，不代表已经验证稳定锁帧。

- 开发者包使用 debug 模式，仅在该包启用开发者权益；邀测包使用 release 模式并关闭开发者开关。
- 构建使用正式 Release SDK，签名配置仅保留本机，不提交仓库。
- 构建、回归和实机安装结果记录在本次产物目录；既有调试截图不作为本版本重新验证的证据。
- 生成邀测包不代表上传 AppGallery Connect 或提交审核；未执行的书源端到端、支付、云服务和手表实机验证不计入验收。
