# 简听 v0.1.46 更新日志

日期：2026-10-08。版本：0.1.46 / 1000046，最低 HarmonyOS 6.0（API 20），目标 API 26。

## 详情与搜索

- 重新组织详情页封面、书籍信息、标签和简介，支持深浅色主题与沉浸式顶栏。
- 提供加入书架/已在书架、查看目录、换源和阅听记录快捷入口，顶栏同步收藏状态。
- 目录移入独立弹层，支持搜索、正倒序、列表/分段切换及定位当前章节；返回操作优先关闭弹层。
- 底部提供阅读/听书和继续阅读/收听按钮；点击分类标签可带关键词直接进入搜索。

## 首页榜单

- 小说榜单以每列两本横向排列，最多展示六本，并露出下一列提示滑动。
- 完整榜单展示上限调整为 99 项，保留来源返回的实际数量。

## 导入书源兼容

- 补充空值请求头传输兼容，从书籍 URL 初始化 book_id/bookId 变量，改善依赖这些字段的接口请求。
- 完善正文净化规则、替换模板和段落处理；大载荷脚本使用最长 5 秒的受限执行预算，仍由原生中断兜底。
- 首次 DOM 解析宿主挂载等待上限由 5 秒调整为 20 秒，降低冷启动解析失败概率。
- JSON 响应中的 html/@html 返回原始文本，后接脚本保持字符串语义；显式 JSON 字段仍通过 JSONPath 获取。
- 补充音频 JSON 地址候选字段，减少非媒体链接误判，将最终响应地址纳入音频匹配，并扩展音频类型声明识别。

## 分发与验证边界

- 开发者包使用 debug 模式，仅在该包启用开发者权益；邀测包使用 release 模式并关闭开发者开关。
- 构建使用正式 Release SDK，签名配置仅保留本机，不提交仓库。
- 构建、回归和实机安装结果记录在本次产物目录；既有调试截图不作为本版本重新验证的证据。
- 生成邀测包不代表上传 AppGallery Connect 或提交审核；未执行的书源端到端、支付、云服务和手表实机验证不计入验收。
