# 简听 v0.1.43 邀测更新说明

版本：`0.1.43` / `1000043`。最低 HarmonyOS 6.0 / API 20，目标 API 26。

## 阅听记录

- 每本书新增时钟图标，进入独立的会话历史；与阅读/播放图标紧邻并上移，章节行独立展示。
- 历史记录改为时间轴，展示每次会话的起止时间、章节、播放时间或阅读字位置，支持跳回开始和停留位置。
- 适配状态栏与底部安全区，使用与现有页面一致的 HDS 沉浸渐变模糊标题栏。
- 保留最近 2000 条章节会话，异常退出以最后保存位置为准；不会补造升级前不存在的会话。
- 删除书籍、清空记录或清理缓存均保留累计及每日收听时长；恢复旧备份不降低本机累计。仅设置页独立的“清除累计收听时长”经确认后清零统计。

## 朗读与播放

- 系统 TTS 改由系统合成 PCM、应用内播放器输出，真实播放完成后再推进位置；增加乱序包重排、去重、缺包和内存预算检查。
- 后台音频任务更新去重，取消定时重复申请；增加锁屏播放、系统挂起及失败诊断日志。
- 完整音频缓存未就绪时立即使用网络拉流，移除原先最多 1200ms 的缓存等待，减少起播延迟。
- 补齐音频播放失败时的会话结束记录。

## 预缓存与搜索

- 预缓存设置支持 0–50 章，应用成功后立即按新数量调度，旧任务失效；保存期间防止重复提交，失败回滚并提示。
- 搜索并发应用后明确提示成功或失败，成功保存后供下次搜索使用，重启保持；新增实际并发调度日志。

## 主题会员、书源与备份

- 新增终身主题会员，显示“长期有效”，独立查询非消耗型商品并核验签名订单及退款状态；商品不可售时不伪造价格。
- 已有月度/年度会员购买终身会员前提示主动关闭原订阅续费，不自动取消订阅。
- 个人中心和账号页按会员类型显示昵称配色，新增终身会员徽标。
- 非会员最多导入 8 个自定义源，禁用源计入，同地址更新不占新名额；会员到期保留已有超额书源，超限导入明确提示并回滚。
- 自动云备份及周期设置按已核验会员权益开放；非会员仍可手动云备份与恢复。

## 稳定性与验证范围

- 未收藏记录增加页面进入、书籍缺失、加载与恢复失败日志。本轮未复现偶发闪退，也未取得对应崩溃堆栈，不能认定删除书源是原因或宣称已修复闪退。
- 系统 TTS 模拟器实际息屏超过 12 分钟仍推进位置；真机省电策略、耳机和主观音质尚未验收。
- 模拟器验证了会话展示及跳回、设置成功提示和重启保持；定向测试覆盖 TTS、音频命令、PCM、历史记录、累计统计和并发设置。
- 用户提供的测试书源仅导入模拟器，不随安装包内置。在线有声书的完整播放、预缓存、下载和导出闭环尚未验收；支付及手表硬件也未完成实测。
