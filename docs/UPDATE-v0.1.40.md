# 简听 v0.1.40 更新日志

## 新增功能

- 标准手表新增独立听书界面，可导入 HTTPS 有声书源，搜索、查看目录、播放和管理离线下载。支持在同一系统账号下手动确认恢复云备份中的书架与进度；本地音频文件不会随备份传输。
- 书架新增在线书籍更新检查：每天在前台静默检查一次，也可手动刷新并查看更新数量与最新章节。失败的书源不会影响其他书籍。
- 图标主题增加三款卡通样式，默认及现有图标、阅读勋章资源同步压缩。

## 体验优化

- 手机、折叠屏、平板和 2in1 按实际窗口宽度调整书架、搜索、更多页面与设置布局；宽屏阅读正文限制行宽，并支持键盘方向键和翻页键。
- 全网榜单优先显示已缓存内容，再逐榜更新；当前平台优先刷新，封面在窗口变宽时保持稳定尺寸。
- 书卡封面进入详情时，等待详情封面加载完成后再淡出转场截图，减少一镜到底交接时的闪烁。

## 修复与兼容

- EPUB 解析组件改为按需加载，并在系统不支持 ReaderKit 时给出明确提示，避免影响普通文字阅读和本地导入。
- 完善阅读位置恢复、窗口安全区与桌面窗口关闭处理；书源扫码入口增加能力检查。
- 保持最低 HarmonyOS 6.0 / API 20、目标 API 26。`liteWearable` 和 API 20 以下设备不在本版支持范围内。
