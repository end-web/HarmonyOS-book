# 简听 v0.1.45 更新日志

日期：2026-10-07。版本：0.1.45 / 1000045，最低 HarmonyOS 6.0（API 20），目标 API 26。

## 会员与个人中心

- 会员中心移到“我的”账号卡片下方，主题入口独立命名为“主题”。
- 重新设计会员弹框：金色权益卡、终身/年度/月度套餐、对应会员图标，布局更舒展；终身套餐优先展示。
- 更换永久会员 LIFE VIP 图标，处理透明背景，兼容深浅色页面；会员权益新增“专属客服”说明。
- 正式版恢复会员权益限制：会员可使用专属主题图标、自动云备份及周期设置、不限总数的书源导入和 1–12 搜索并发。非会员保留默认主题、手动备份、最多 8 个书源和默认 3 路搜索；已有超额书源保留。
- 交流群更新为“简听交流群2”，群号 602330717。

## 阅读与书架

- 新增阅读页面四角信息位置设置，可调整书名、章节标题、章节序号和页码的位置，支持保存及备份恢复。
- 书架封面增加书源名称标签；删除书源后继续保留收藏、阅听记录和进度，并可通过换源继续使用。
- 修复书架打开书籍时返回回调的声明顺序问题。

## 书源与备份

- 完善光遇导入书源的小说/听书兼容：同步线路、超时、搜索平台、网络模式等设置，优化账号登录、发现面板、详情、目录和内容请求。
- 完善书源文件批量导入达到会员数量上限时的提示与结果反馈。
- 云服务暂未就绪时增加有限次数重试，支持取消和账号隔离，失败提示更明确并保留已有云备份。
- 整理听友 FM v3 规则示例供手动导入，不作为内置书源。

## 资源整理

- 删除未引用的旧头像、启动图、网络配置和旧图标候选素材。
- 清理本地试稿、截图、日志与临时包，工作区减少约 334 MiB；该数字不是安装包缩减量。
