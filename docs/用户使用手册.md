## 1. 快速开始

ListenBook 是一款**无内置书源**的听书应用，需要先导入书源才能搜索和播放内容。

**三步开始使用：**

1. 打开 App → 点击底部导航栏「书源」Tab
2. 点击右上角「+」→ 粘贴书源订阅链接 → 导入
3. 回到「首页」→ 在搜索框输入书名 → 开始搜索

---

## 2. 主界面导航

App 底部有四个主 Tab：

| Tab | 图标 | 功能 |
|-----|------|------|
| **首页** | 🏠 | 搜索书籍 |
| **书架** | 📚 | 收藏的书籍 |
| **书源** | 🔌 | 管理书源订阅 |
| **我的** | 👤 | 收藏、历史记录、设置 |

> 💡 可在「设置」中更改启动时默认打开的 Tab。

## 3. 首页 · 搜索

### 搜索书籍

1. 在顶部搜索框输入书名或作者名
2. 点击键盘「搜索」键
3. App 会**并行查询所有已启用书源**，结果自动聚合显示

### 搜索结果

- 结果卡片显示：书名、作者、书源来源、封面
- 点击书卡 → 进入**书籍详情页**
- 同一本书可能来自多个书源，均会列出

### 注意事项

- 搜索需要至少一个**已启用的文本书源**
- 界面顶部会提示当前启用的书源数量
- 网络异常时单个书源报错不影响其他书源结果

---

## 4. 书架

书架展示所有**已收藏**的书籍，方便快速找到常听的书。

- 点击书卡 → 进入书籍详情页
- 长按书卡 → 可移除收藏（视具体实现）
- 上次播放记录会在 App 启动时自动恢复到播放器底部迷你条

## 5. 书源管理

### 什么是书源？

书源是提供书籍搜索与播放数据的规则配置文件（JSON 格式），类似「插件」。ListenBook 不内置任何书源，需要用户自行导入。

### 导入书源

**方式一：链接导入**
1. 书源 Tab → 右上角「+」
2. 粘贴书源 URL（支持单条 JSON 或 JSON 数组）
3. 点击「导入」

**方式二：文件导入**
1. 书源 Tab → 右上角「导入」图标
2. 选择本地 `.json` 书源文件

### 管理书源

| 操作 | 说明 |
|------|------|
| 开关切换 | 启用/禁用单个书源，禁用后搜索时跳过 |
| 删除 | 移除该书源（不影响已收藏书籍） |
| 刷新/编辑 | 更新书源配置 |

### 书源类型

- **文本书源**（bookSourceType=0）：提供文本章节，可配合 TTS 朗读
- **音频书源**（bookSourceType=1）：直接提供音频 URL 播放

## 6. 书籍详情页

点击任意书卡进入详情页，包含：

### 基本信息
- 封面、书名、作者、简介
- 来源书源名称

### 操作按钮
| 按钮 | 功能 |
|------|------|
| ❤️ 收藏 / 取消收藏 | 添加/移除书架 |
| ▶️ 播放 | 从第一章或上次进度开始播放 |
| 继续播放 | 从上次记录的章节和进度续播 |

### 章节列表
- 切换「章节」Tab 查看目录
- 若章节列表为空，App 会自动从书源拉取目录
- 点击章节直接跳转播放

## 7. 播放器

### 进入播放器

- 点击底部**迷你播放条**（MiniPlayer）展开全屏播放器
- 或在书籍详情页点击播放按钮直接进入

### 播放控制

| 控件 | 功能 |
|------|------|
| ⏮ 上一章 | 切换到上一章节 |
| ⏭ 下一章 | 切换到下一章节 |
| ▶️ / ⏸ | 播放/暂停 |
| 进度条 | 拖动跳转到任意位置 |
| 🔁 播放模式 | 顺序/单章循环/列表循环 |
| 速度 | 0.75x / 1.0x / 1.25x / 1.75x / 2.0x |

### 章节列表

点击右下角「章节」按钮 → 弹出章节抽屉，可快速切换章节。

### 睡眠定时器

点击「定时」按钮 → 选择自动停止播放的时间（如 15 分钟、30 分钟等）。

### 封面主题色

播放器背景会根据封面图自动提取主题色，首次打开略有延迟。

### 后台播放

切换到其他 App 或息屏后，音频继续播放。  
锁屏/控制中心会显示**媒体卡片**，支持直接控制播放/暂停/切章。

### 迷你播放条（MiniPlayer）

在非播放器页面，底部会悬浮显示迷你播放条，包含：
- 封面缩略图、书名、章节名
- 播放/暂停按钮
- 点击条目区域展开全屏播放器

## 8. 文本阅读模式

> 适用于**文本书源**，将章节文字通过 TTS（文字转语音）朗读。

### 进入文本阅读模式

在书籍详情页 → 点击「阅读」按钮（或播放器内切换）

### 功能

- 文字随朗读高亮显示当前段落
- 支持上下章翻页
- TTS 速度跟随播放器速度设置
- 同样支持后台朗读和锁屏控制

## 12. 常见问题

### Q：搜索无结果
- 确认已导入并**启用**至少一个书源
- 检查网络连接
- 尝试更换搜索关键词

### Q：书源导入失败
- 确认书源 JSON 格式正确
- 检查 URL 是否可访问
- 部分书源需要科学上网

### Q：播放器没有声音
- 检查手机音量
- 检查是否被其他 App 占用音频焦点
- 进入设置调整「音频焦点模式」

### Q：后台播放停止
- 确认 App 有「后台运行」权限（系统设置 → 应用 → ListenBook → 电池）
- 部分品牌 ROM 有激进的后台清理，需手动加入白名单

### Q：章节列表加载慢
- 章节目录从书源实时拉取，网络较慢时等待即可
- 确认书源规则支持目录解析

### Q：如何切换书源播放同一本书？
- 在搜索结果中选择来自不同书源的同名书籍
- 进入各自的详情页单独播放
