# 简听 v0.1.44 邀测更新说明

版本：`0.1.44` / `1000044`。最低 HarmonyOS 6.0 / API 20，目标 API 26。

## 功能开放

- 桌面图标、自动云备份及周期设置、导入书源数量全部免费，不再受会员限制。
- 移除购买入口，保留历史订阅管理；已有订阅用户可进入管理页面取消续费。
- 图标切换仍需 API 26，自动备份仍需登录并主动开启。

## 书源与播放

- 优化导入书源的音频地址解析及浏览器辅助解析流程。
- 优化章节预加载、音频缓存和下载策略。
- 优化播放器操作与反馈，同步调整书源管理和相关说明。
