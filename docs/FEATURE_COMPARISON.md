# 功能对比：ListenBook vs 开源轻页（Legado Harmony）

## 概述

本文档对比 **ListenBook**（简·欢）和 **开源轻页（Legado Harmony）** 两个 HarmonyOS 阅读应用的功能差异，用于明确产品定位和后续开发方向。

---

## 基本信息对比

| 项目 | ListenBook | 开源轻页 |
|---|---|---|
| **定位** | 本地优先听书与小说阅读 | 综合性本地阅读应用 |
| **设备支持** | 仅 `phone` | `phone`、`tablet`、`2in1` |
| **目标 API** | HarmonyOS 7 / API 26 | HarmonyOS API 23 |
| **最低 API** | API 26 | API 12 |
| **包名** | `com.huan.listenbook` | `io.legado.read` |
| **版本** | 0.1.6 | 3.8.838 |
| **开源协议** | - | GPL-3.0 |

## 技术架构差异

### ListenBook 的技术特点
- **更简洁的架构**：单模块、仅手机端
- **听书优先**：AVPlayer + 系统媒体控制
- **服务端支持**：可选独立聚合服务（Node.js + Vue）
- **QuickJS 双 ABI**：arm64-v8a + x86_64

### 开源轻页的技术特点
- **更完整的阅读器**：多设备、多格式、多引擎
- **原生 V2 分页**：ReaderV2Document、增量分页、原生选区
- **多脚本引擎**：QuickJS + ArkWeb 双运行时
- **主题系统**：ThemePack + 运行时令牌
- **云同步**：WebDAV + 华为账号
- **复杂调度**：协作式调度、耗时保护、取消传播

## 优先级建议

### 🔴 高优先级（核心体验）

1. **发现页**：独立发现入口、书源榜单和分类
2. **TTS 朗读**：系统 TTS + 文字朗读（非有声书）
3. **书源高级功能**：校验模式、WebView 支持、会话规则
4. **搜索增强**：精准搜索、作者匹配、分组筛选
5. **换源功能**：多书源切换
6. **目录搜索**：快速定位章节

### 🟡 中优先级（增强体验）

1. **漫画阅读器**：连续全宽显示
2. **WebDAV 备份**：跨设备数据迁移
3. **自定义主题**：主题包、颜色、字体
4. **本地书籍增强**：批量导入、分组、置顶
5. **书签管理**：收藏章节和段落
6. **全文缓存**：后台缓存+通知
7. **正文替换规则**：文本净化

### 🟢 低优先级（锦上添花）

1. **平板和 2in1 适配**
2. **眼动翻页**
3. **仿真翻页**（页面卷曲）
4. **正则字体样式**
5. **华为账号云同步**
6. **应用图标切换**
7. **封面图库管理**

---

## 总结

**ListenBook** 当前已具备基础的听书和阅读能力，但相比 **开源轻页** 在以下方面有明显差距：

1. **阅读器成熟度**：缺少 V2 分页、漫画、书签、替换规则等
2. **TTS 系统**：完全缺失文字朗读能力
3. **发现页**：没有独立发现入口
4. **主题系统**：只有 5 个固定主题，无自定义能力
5. **数据同步**：缺少 WebDAV 和云同步
6. **本地书籍**：管理功能较弱

建议优先实现 **发现页**、**TTS 朗读**、**WebDAV 备份** 和 **搜索增强** 以提升核心竞争力。
