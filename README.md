# 简听阅读

想读的时候，静享文字；想听的时候，让故事继续。

简听是一款面向 HarmonyOS 的电子书阅读与有声书播放工具，集书源导入、本地小说阅读、电子书管理和音频播放于一体。操作简单，界面优美。从通勤途中到睡前片刻，用喜欢的方式，接着读、继续听。

## 自主导入书源，打造个人阅读空间

支持自行导入和管理书源，在来源支持且已获相应授权的前提下，搜索小说、阅读电子书、播放有声书。支持书源分组与可用性测试，方便整理常用来源。实际内容与可用性取决于所导入的书源。

## 导入电子书，建立个人文库

支持 TXT、EPUB、MOBI、HTML/HTM 等格式的电子书导入，以及 ZIP 批量导入。将自己的小说与文字读物收入书架，集中整理，随时翻阅。具体支持范围以应用内说明为准。

## 自在阅读，页面由你定义

自由调整字号、行距、字重、阅读主题与背景，支持字体导入与多种翻页设置。记录章节和阅读位置，再次打开，接着上次的故事。

## 自在收听，让故事继续

支持本地音频导入，提供倍速播放、睡眠定时、跳过片头片尾和播放进度记忆。通勤、休息、做家务时，也能轻松收听。

## 文字朗读，多一种读书方式

通过系统语音以及自定义TTS朗读文字内容，让小说和电子书也能听着读。语音效果与可用能力取决于设备及系统支持。

## 书架与阅听记录，留下阅读足迹

收藏喜欢的书籍，查看阅读与收听记录，管理个人阅读进度，让分散的电子书和有声书井然有序。

在简听，把喜欢的书收进书架，把阅读融入日常。

## 内容与权益说明

简听提供阅读、播放及内容管理工具，不内置小说正文或有声书音频资源。请仅导入、访问和使用您拥有合法使用权的文件与内容，并遵守相关法律法规及来源平台的服务条款。应用会员权益仅适用于应用功能，不包含第三方作品的购买、订阅或访问授权。部分功能需要付费，具体以应用内展示为准。
